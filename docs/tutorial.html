Tutorial e especificação do INPIOJUS

Documento oficial da versão 1.0.0, assinado por Joaquim Pedro de Morais Filho · zicutake@mail.ru

O que é o INPIOJUS? Sistema web de IA jurídica assistiva que lê decisões/autos (texto ou PDF) e gera petições ou resumos com estrutura argumentativa, usando o modelo generativo Google Gemini. Não é órgão do governo; o visual institucional é de apresentação.

2. Como a IA é usada

O motor central é a API generateContent do Gemini. Cada geração combina duas camadas de texto:

CamadaNome técnicoFunção no INPIOJUS
System instruction systemInstruction Define o papel da IA: redator jurídico formal, respeito ao rito, estrutura da peça, tom profissional.
User prompt contents[].parts[].text Traz os autos/decisão, dados do impetrante, tribunal destino e o tipo de peça escolhida.
Resposta candidates[0].content Texto da petição ou resumo, depois exibido e opcionalmente convertido em PDF. 
Browser (INPIOJUS)
   │  PDF → pdf.js → texto
   │  ou textarea (autos)
   ▼
processWithGemini(userPrompt, systemPrompt)
   │  POST generativelanguage.googleapis.com
   │  model: gemini-2.0-flash (configurável)
   ▼
Texto jurídico gerado → tela / PDF

Chave API: salva só no localStorage (inpiojus_gemini_key). Nunca é enviada ao GitHub. Obtenha em Google AI Studio.

3. Argumentos jurídicos no projeto

Os argumentos não são um banco de jurisprudência fixo: a IA é instruída a montar raciocínio em camadas típicas do processo brasileiro:

  1. Qualificação — partes, foro, impetrante / jus postulandi
  2. Fatos — extrair da decisão impugnada os pontos controvertidos
  3. Direito — fundamentos constitucionais/legais adequados ao rito
  4. Pedido — o que se requer (liminar, provimento, reforma, etc.)
  5. Fecho — local, data, assinatura / advogado ou parte

Ritos disponíveis na interface (botões principais):

BotãoPeça / usoFoco argumentativo
Habeas CorpusHCLiberdade / ilegalidade de coação
EmbargosEmbargos de declaraçãoOmissão, contradição, obscuridade
RecursoRecurso genérico / reformaError in judicando / procedendo
MandadoMandado de segurançaDireito líquido e certo
Agravo regimentalAgRgReforma de decisão monocrática
Agravo internoAgIntÓrgão colegiado / regimento interno
ResumoSínteseMapa da decisão e pontos de ataque
A IA pode alucinar citações de lei ou jurisprudência. Todo argumento deve ser conferido em fonte oficial (Planalto, tribunais, diários) por profissional habilitado.

4. Fluxo de uso (passo a passo)

  1. Abra o app e clique Configurar API Gemini.
  2. Cole a chave e, se quiser, o nome do modelo.
  3. Envie um PDF da decisão ou cole o texto na caixa.
  4. Preencha impetrante / CPF / cidade (modal) ou mantenha padrão.
  5. Escolha o tribunal destino quando solicitado.
  6. Clique no rito desejado (HC, embargos, etc.).
  7. Aguarde a IA; revise o texto gerado.
  8. Baixe o PDF se a opção estiver disponível.

6. Ética e limites

  • Uso assistivo — não substitui advogado ou defensor público.
  • Não protocolar peça sem revisão humana completa.
  • Não inserir dados sensíveis de terceiros em serviços de nuvem sem base legal (LGPD).
  • Proibido uso para falsidade, fraude processual ou simulação de atos oficiais.
